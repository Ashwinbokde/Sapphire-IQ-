# 📊 Amazon India Sales Analysis

An Excel-based data analytics project focused on analyzing Amazon India sales data to identify sales trends, evaluate product performance, understand customer order behavior, and generate actionable business insights.

## 📌 Project Overview

This project analyzes Amazon India sales data using Microsoft Excel. It includes data analysis, KPI calculations, visualizations, and an interactive dashboard to understand sales performance, profitability, order statuses, payment methods, fulfilment methods, and geographical trends.

The project aims to transform raw sales data into meaningful insights that can support better business decisions.

## 🎯 Project Objectives

- Analyze total sales, profit, orders, and units sold.
- Calculate Average Order Value (AOV) and profit margin.
- Identify monthly sales and profit trends.
- Compare sales and profit across product categories.
- Identify top-performing products.
- Analyze delivered, shipped, returned, and cancelled orders.
- Calculate return and cancellation rates.
- Compare payment methods and fulfilment methods.
- Identify high-performing states based on sales and profit.
- Develop an interactive Excel dashboard using charts and slicers.

## 🛠️ Tools & Technologies

- **Microsoft Excel** — Data analysis and dashboard development
- **PivotTables** — Data summarization and aggregation
- **Excel Formulas** — KPI and business metric calculations
- **Charts & Visualizations** — Performance analysis
- **Slicers** — Interactive dashboard filtering
- **GitHub** — Project documentation and version control
